# Nuvaryn 使用說明

Nuvaryn 是一位**會說話、有表情、能用你的語言陪你聊天的 AI 伙伴**。
預設角色是 **Iris**;她的大腦跑在你自己的 Mac mini 上(見[安裝手冊](install-mac-mini.md)),
手機只是她的臉與聲音。

---

## 第一次打開

四頁導引會介紹她能做什麼與如何連線。最後一頁兩個選擇:

- **試試示範模式**——不需要任何伺服器,Iris 會用預先準備的台詞跟你互動,聲音、表情、嘴型都是真的。適合先感受一下。
- **我已經有 Gateway,去設定**——直接填入 Mac mini 的連線資訊。

示範模式隨時可以從 **設定 → 試試示範模式** 再進入;狀態列的「離開示範」或按「連線」即離開。

## 主畫面(聊天頁)

| 位置 | 功能 |
|---|---|
| 左上 🔊 | 語音開/關(關閉後只顯示文字) |
| 左上 👤 | 進入**舞台**(全螢幕 3D 角色) |
| 右上 ✏️ | **開新對話**(封存目前歷史;本地模型或話題切換時建議使用) |
| 右上 ⚙️ | 設定 |
| 狀態列 | 綠燈=已連線、延遲毫秒數;右側「連線 / 中斷」 |
| 下方 🎙️ | 語音輸入:按一下開始聽,再按一下送出 |
| 下方輸入框 | 打字;往下滑動對話列表或點空白處可收鍵盤 |

## 舞台(與 Iris 面對面)

- 第一次進入請**點一下畫面**喚醒聲音(iOS 規定,音訊必須由你的觸碰啟動)。
- 頂部膠囊顯示目前角色,點開可切換 **Iris / Iris (US) / Lucas / Lucas (US)**;女聲、男聲會跟著換。選擇會記住。
- 字幕隨她說話逐字浮現;她的表情與手勢由她自己在回覆中標註(你看不到標記,只看到表情)。
- 若 app 在背景放久了,iOS 可能回收舞台;回來後會自動重載,**再點一下畫面**即可恢復聲音。

## 自然對話(免持)

設定 → 語音 → **自然對話(免持)** 開啟後,麥克風按鈕變成「免持開關」:

1. 按一下 → 進入免持(麥克風橘色常亮)。
2. 說完話**停頓約 1.5 秒**就自動送出。
3. Iris 回答時麥克風暫停(她不會聽到自己),答完自動繼續聽你說。
4. 再按一下麥克風 → 結束。

適合一邊做事一邊聊。目前為「輪流說」的模式;插話打斷她的功能在規劃中。

## 20 種語言

Iris 會**用你說的語言回答**,聲音與嘴型一起切換,不需要任何設定:
英文、繁體中文、简体中文、日文、韓文、西班牙文、印地文、法文、德文、葡萄牙文、阿拉伯文、印尼文、義大利文、越南文、土耳其文、泰文、俄文、荷蘭文、波蘭文、菲律賓文、孟加拉文。

設定 → 語言 可微調:

- **語音輸入語言**:你對麥克風說的語言(預設繁體中文;「自動」跟隨系統)。
- **偏好語言**:回覆是拉丁字母時優先採用的發音語言。菲律賓語等自動偵測認不出的語言請在這裡指定。
- **阿拉伯語方言**:標準(MSA)/ 埃及 / 海灣 / 黎凡特 / 摩洛哥——文字本身無法分辨方言,請手動選。

## 模型

設定 → 模型,依 **OpenAI / Anthropic / Gemini / OpenRouter / 本地** 分組選擇;切換後從下一則回覆生效,選擇存在伺服器端。
OpenRouter 餘額會顯示在這裡(其他家官方不提供餘額查詢)。

| 想要 | 建議 |
|---|---|
| 日常、便宜 | GPT(gpt-5.4-mini)、Claude Haiku、Gemini Flash |
| 品質優先 | Claude Sonnet |
| 極省 | DeepSeek(經 OpenRouter) |
| 斷網 / 隱私 | Local Qwen(見下方限制) |

---

## 金鑰

設定 → 金鑰:
- **Gateway Token**:這支手機連上你 Mac mini 的通行證。
- **OpenAI / Anthropic / Gemini / OpenRouter**:Mac mini 連上各家 AI 的鑰匙。貼上後按「套用」,會安全寫入 Mac mini 並自動重啟服務(約 10 秒重連)。
所有金鑰只存在 iPhone 的 Keychain 與你的 Mac mini,不會上傳任何地方。

## 已知限制(請先看)

1. **示範模式 / 離線時的男聲**:示範模式與伺服器語音不可用時,app 使用 iPhone 內建語音。iPhone **出廠通常沒有中文男聲**,此時 Lucas 會暫時是女聲。
   解法:**設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文** 下載一個男聲,app 會自動選用。英文男聲通常已內建。
   連上 Mac mini 的正式模式不受影響(雲端男聲一直都在)。
2. **本地模型沒有人格、不會用工具**:OpenClaw 目前對 Ollama 模型不注入系統提示(上游已知問題),所以 Local Qwen 不會自稱 Iris、查不了天氣。請當作斷網備援。
3. **舞台喚醒**:每次舞台重載後需點一下畫面才有聲音(iOS 音訊政策)。
4. **語音辨識**:iOS 的辨識工作階段約 60 秒會重啟一次;免持模式會自動處理,單次長篇請分段說。
5. **插話打斷**:目前 Iris 說話時你的聲音不會被接收;此功能規劃中。
